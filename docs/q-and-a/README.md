# Question and answer log

Questions asked while building this, with their answers, kept so they can be
revisited and used for self-testing.

Each answer sits inside a collapsible block. Read the question, try to answer it
yourself, then expand to check. Entries are dated so the progression is visible.

- [nix.md](nix.md) — Nix and NixOS
- [shell-and-unix.md](shell-and-unix.md) — shell behaviour and Unix conventions
- [practices.md](practices.md) — ways of working, documentation, process

Questions about project state, or about what to do next, are not logged here.
Those belong in issues.
